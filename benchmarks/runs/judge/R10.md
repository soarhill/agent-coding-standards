## 1. Correctness — 30/30

- Bug 1: both divergent mappers are replaced by one shared function backed by a constant map. The removed code shows the original defect — table mapper `0 'Uploading', 1 'Pending', 2 'Vectorizing', 3 'Completed', 4 'Failed'` versus shifted dialog mapper `0 'Pending', 1 'Vectorizing', 2 'Completed', 3 'Failed'` — and the replacement carries the full, table-authoritative range:
  ```js
  const STATUS_TEXT = {
    0: 'Uploading',
    1: 'Pending',
    2: 'Vectorizing',
    3: 'Completed',
    4: 'Failed',
  }

  function statusText(status) {
    return STATUS_TEXT[status] ?? 'Unknown'
  }
  ```
  with both call sites unified:
  ```diff
  -      <span>{{ tableStatusText(file.status) }}</span>
  +      <span>{{ statusText(file.status) }}</span>
  ...
  -      <p>Status: {{ editStatusText(editingFile.status) }}</p>
  +      <p>Status: {{ statusText(editingFile.status) }}</p>
  ```
  The `?? 'Unknown'` fallback reproduces the old chains' fall-through for unmapped codes.
- Bug 2: identity key replaces positional key:
  ```diff
  -      v-for="(file, index) in files"
  -      :key="index"
  +      v-for="file in files"
  +      :key="file.id"
  ```
  fixing the `v-model="file.note"` mis-binding on reorder. The unused `index` binding is dropped.
- Backend codes unchanged (values re-expressed, not altered); no API, styling, or markup-structure changes; Composition API retained; no dependencies.
