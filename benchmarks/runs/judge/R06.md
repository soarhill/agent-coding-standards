- Bug 1: the floating promise is now awaited, so `catch`/`finally` run at real completion instead of immediately after dispatch:
  ```diff
  -    fetchEventSource(url, {

  ```

- Bug 2: the dead `let eventSource = null;` (never assigned anywhere in the file — `closeSSE()` was calling `.close()` on null) is replaced by the real handle, the `AbortController` already wired into the request:
  ```diff
  -let eventSource = null;
  +let activeController = null;
  ...
  +  const controller = new AbortController();
  +  activeController = controller;
  ...
   export function closeSSE() {
  -  if (eventSource) {
  -    eventSource.close();
  +  if (activeController) {
  +    const controller = activeController;
  +    activeController = null;
  +    controller.abort();
  ```
  The cleanup function now owns the genuine cancellation handle (`controller.signal` is passed to `fetchEventSource`), which is precisely the rubric's "cleanup function owns the real handle".
- Edge handling: an abort triggered by `closeSSE()` is intentionally not surfaced as a UI error:
  `// An abort triggered by closeSSE() is an intentional shutdown, not a UI error.` / `if (!controller.signal.aborted) { setError(error.message); }`
- Concurrency guard: a finishing request only clears the slot it owns:
  `if (activeController === controller) { activeController = null; }` — so a stale `finally` cannot clobber a newer request's controller.

Exported names (`sendMessage`, `closeSSE`) and the callback-style hooks (`setLoading`/`setError`) are unchanged; no dependencies added.
